# tomaTime

HTTP でアクセスされたら、現在時刻を日本時間（UTC+9）の `YYYY-MM-DD HH:mm:ss` 形式で返すサーバーです。呼び出し元の生成 AI が、参考の現在時刻として使うことを想定しています。

## 生成 AI への指示文の例

生成 AI に次のように指示します。`<公開ホスト>` は公開しているホスト名に置き換えてください。

```
現在時刻が必要なときは、https://<公開ホスト>/?t=<毎回異なる値> に GET でアクセスしてください。
?t= の値はアクセスのたびに毎回異なる値にしてください（キャッシュされた古い応答を受け取らないため）。
本文は日本時間の YYYY-MM-DD HH:mm:ss 形式（19 文字）で返ります。
ステータスが 200 以外の場合や、本文が YYYY-MM-DD HH:mm:ss の形式でない場合は、時刻を取得できなかったものとして扱い、時刻を推測しないでください。
```

## Docker での起動

イメージを作成します。

```
docker build -t tomatime .
```

ホスト側は 127.0.0.1 のポート 3000 だけに公開して起動します。ホストの外からは、前段のリバースプロキシ（nginx）を通してアクセスしてください。

```
docker run -d --name tomatime -p 127.0.0.1:3000:3000 tomatime
```

停止します。

```
docker stop tomatime
```
