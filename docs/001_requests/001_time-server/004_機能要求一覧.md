### REQ-1 の補足

- 「その時点」は、要求を受けて応答を作るときに OS の時計から取得した値を指す（C-5）
- 日本時間は OS やコンテナのタイムゾーン設定に関係なく UTC+9 で求める（D-2、REQ-10）。コンテナ内のタイムゾーンは UTC の場合もある（AI の解釈）
- どのパスにも時刻を返すため、誤った URL や第三者の任意のパスへの GET にも時刻が返る（D-13 の補足の残るリスク）
- 秒未満の扱い（切り捨てか四捨五入か）は要件定義で決める（[要件定義への申し送り](009_確認事項.md#要件定義への申し送り)）
