## モジュール構成

| ID | ファイル | 責務 | 依存先 | 対応要件 |
|---|---|---|---|---|
| M-1 | `src/clock.ts` | 時刻の取得元の型 `Clock` と、OS の時計を読む本番の実装 `systemClock`（`Date.now()` を返すだけ）。`Date.now()` を呼ぶのはこのモジュールだけ | - | FR-1, NFR-1, NFR-3, NFR-7 |
| M-2 | `src/format.ts` | 整形。取得した値の検査（有限の数か、日本時間が有効範囲内か）、UTC+9 への換算、秒未満の切り捨て、`YYYY-MM-DD HH:mm:ss` への整形。状態を持たない純粋な関数 | - | FR-1, FR-4, NFR-2 |
| M-3 | `src/failure.ts` | 500 の原因の型 `TimeFailure` と、標準エラー出力へ書く 1 行 `time unavailable: <原因>` と LF の組み立て（CR・LF の置き換えを含む） | - | FR-4, FR-10 |
| M-4 | `src/handler.ts` | 1 件の要求の処理。メソッドの判定、取得（M-1 の `Clock` を 1 回呼ぶ）、整形（M-2）、応答の組み立てと送信、500 のときの 1 行の書き込み。処理の全体を 1 つの例外処理で囲む | M-1（型だけ）, M-2, M-3 | FR-1, FR-2, FR-3, FR-4, FR-5, FR-10, NFR-1, NFR-3, NFR-5 |
| M-5 | `src/server.ts` | `http.createServer` で M-4 の処理を持つ `http.Server` を作って返す。待ち受け（`listen`）はしない。Node.js の既定の設定・イベントの扱いを変えない | M-4 | FR-6, NFR-3 |
| M-6 | `src/config.ts` | 環境変数 `TOMATIME_HOST`、`TOMATIME_PORT` の検査と既定値の適用。値を受け取って結果を返す純粋な関数 | - | FR-7 |
| M-7 | `src/main.ts` | 起動の入口（`npm start` と `Dockerfile` の `CMD`）。M-6 で設定を読み、M-5 に本番の取得元（M-1 の `systemClock`）と書き込み先（`process.stderr`）を渡し、待ち受け、起動時の出力、起動の失敗、SIGINT・SIGTERM での終了を扱う | M-1, M-5, M-6 | FR-7, FR-8, FR-11, NFR-6 |

### 依存関係

```
M-7 (main) → M-6 (config)
M-7 (main) → M-1 (clock: systemClock)
M-7 (main) → M-5 (server) → M-4 (handler) → M-2 (format)
                                         → M-3 (failure)
                                         → M-1 (clock: 型 Clock だけ)
```

### モジュール全体の決まり

| 決まり | 内容 | 根拠 |
|---|---|---|
| 状態を持たない | どのモジュールにも、取得した時刻、整形した文字列、応答を保持する変数（モジュールの変数、クロージャの変数、キャッシュ）を置かない。モジュールの定数は固定の本文、ヘッダーの値、有効範囲の境界の数値だけ | NFR-1、TS-2、TS-3 |
| `process` に触れる範囲 | `process.env`、`process.stdout`、`process.stderr`、`process.on`、`process.exit`、`process.exitCode` を使うのは M-7 だけ。M-1〜M-6 は引数で受け取ったものだけを使う | NFR-3、CD-1、CD-2 |
| タイムゾーン | 日本時間の算出に、ローカル時刻の getter（`getHours` ほか `getUTC` の付かないもの）、`toLocaleString` 系、`Intl.DateTimeFormat`、`toString`、`Date.UTC` とフィールド指定の `Date` コンストラクタを使わない | NFR-2、TS-4、FR-1 の補足 |
| 要求の情報 | M-4 が読む要求の情報は `req.method` だけ。URL、クエリ文字列、要求ヘッダー（`X-Forwarded-For` ほか）、本文を読まない | FR-2、FR-3、NFR-5 |
| 外部への通信 | 外部への接続、NTP の照会をしない | NFR-7、TS-1 |
| 入口の分離 | M-7 は読み込んだ時点で起動する入口で、テストから import しない。テストは M-5（と型の M-1、M-4）だけを import する | CD-2 |
