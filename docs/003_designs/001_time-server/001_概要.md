## 概要

承認済みの要件定義書 `docs/002_requirements/001_time-server/` の FR-1〜FR-12、NFR-1〜NFR-8 を、`node:http` だけを使う 7 つのモジュール（M-1〜M-7）と、ts-developer が作るプロジェクト設定・`Dockerfile`・リポジトリ直下の `README.md` で実現する。TypeScript は Node.js の型ストリップで `.ts` を直接実行し（`node src/main.ts`）、ランタイム依存を持たない（NFR-4）。

時刻の安全（`.claude/rules/time-safety.md`）は次のように守る。時刻の取得（M-1 の `Clock` を要求ごとに 1 回呼ぶ）、整形（M-2 の純粋な関数。UTC の getter だけを使い、有限の数でない値と範囲外の値を戻り値で区別する）、応答（M-4。応答の内容を先に組み立ててから送る）を分け、M-4 の要求処理の全体を 1 つの例外処理で囲む。どの段階で例外が起きても、送るのは 500 と固定の本文 `time unavailable`（`Date` なし）か接続の切断だけで、時刻の形式の値を返す経路を持たない（TS-5、CD-4、FR-4）。時刻・本文をプロセス内に保持する変数を置かず（TS-2、NFR-1）、日本時間はエポックミリ秒に 9 時間を足して求め、実行環境のタイムゾーンを使わない（TS-4、NFR-2）。

テストからは、`createTimeServer` の引数で時刻の取得元と 500 の 1 行の書き込み先を差し替え、待ち受けをテスト側の `listen(0)` で行う（CD-1、CD-2、TS-6、NFR-3）。`process` の環境変数・標準出力・標準エラー出力・シグナルに触れるのは起動の入口 M-7 だけとする。
