## 公開インターフェース

モジュールの外から使う型・関数だけを書く。HTTP の応答（ステータス、ヘッダー、本文）、環境変数、標準出力・標準エラー出力の形式は、要件定義書の[インターフェース仕様](../../002_requirements/001_time-server/004_インターフェース仕様.md)と文字単位で同じにする（4.2 節に再掲）。

| モジュール | 名前 | 種類 | シグネチャ | 説明 |
|---|---|---|---|---|
| M-1 | `Clock` | 型 | `() => number` | 呼ぶたびに現在の瞬間を UTC 基準のエポックからのミリ秒で返す（FR-1 の補足） |
| M-1 | `systemClock` | 定数（関数） | `Clock` | 本番の取得元。`() => Date.now()` |
| M-2 | `FormatResult` | 型 | 型定義を参照 | 整形の結果。成功（本文）か、`non-finite`・`out-of-range` のどちらかの理由 |
| M-2 | `formatJst` | 関数 | `(epochMs: unknown) => FormatResult` | 値を検査し、日本時間の `YYYY-MM-DD HH:mm:ss` にする。想定外の例外は投げたままにする（M-4 が `internal` として扱う） |
| M-3 | `TimeFailure` | 型 | 型定義を参照 | 500 にする原因の 4 区分 |
| M-3 | `failureLine` | 関数 | `(failure: TimeFailure) => string` | `time unavailable: <原因>` と LF の 1 行を返す |
| M-4 | `ErrorLineWriter` | 型 | `(line: string) => void` | 500 のときの 1 行の書き込み先。1 件の 500 につき 1 回、LF を含む 1 行全体を 1 回で渡す |
| M-4 | `HandlerDeps` | 型 | `{ clock: Clock; writeErrorLine: ErrorLineWriter }` | 要求処理が使う差し替え点 |
| M-4 | `createRequestHandler` | 関数 | `(deps: HandlerDeps) => RequestListener` | `http.createServer` に渡す要求処理を作る |
| M-5 | `TimeServerOptions` | 型 | `HandlerDeps` と同じ | `createTimeServer` の引数。省略できる項目を持たない |
| M-5 | `createTimeServer` | 関数 | `(options: TimeServerOptions) => http.Server` | 待ち受けていない `http.Server` を返す。テストは `listen(0, '127.0.0.1')` で起動する |
| M-6 | `ListenConfig` | 型 | `{ host: string; port: number }` | 待ち受けるアドレスとポート |
| M-6 | `ConfigResult` | 型 | 型定義を参照 | 設定の検査の結果 |
| M-6 | `parseConfig` | 関数 | `(env: Readonly<Record<string, string \| undefined>>) => ConfigResult` | 環境変数を検査し、既定値を適用する |
| M-7 | - | - | - | 公開しない（入口。読み込むと起動する） |

### 4.1 型定義

```ts
// M-1 src/clock.ts
export type Clock = () => number;
export const systemClock: Clock = () => Date.now();
```

```ts
// M-2 src/format.ts
export type FormatResult =
  | { readonly ok: true; readonly text: string }                       // 19 文字の本文
  | { readonly ok: false; readonly reason: 'non-finite' | 'out-of-range' };

export function formatJst(epochMs: unknown): FormatResult;
```

```ts
// M-3 src/failure.ts
export type TimeFailure =
  | { readonly kind: 'source-threw'; readonly thrown: unknown } // 取得元が例外を投げた
  | { readonly kind: 'non-finite' }                             // 取得元が有限の数でない値を返した
  | { readonly kind: 'out-of-range' }                           // 日本時間が有効範囲外
  | { readonly kind: 'internal'; readonly thrown: unknown };    // 換算・整形・応答の作成での例外

export function failureLine(failure: TimeFailure): string; // 例: "time unavailable: source threw Error: clock read failed\n"
```

```ts
// M-4 src/handler.ts
import type { IncomingMessage, ServerResponse } from 'node:http';
import type { Clock } from './clock.ts';

export type ErrorLineWriter = (line: string) => void;

export interface HandlerDeps {
  readonly clock: Clock;
  readonly writeErrorLine: ErrorLineWriter;
}

export function createRequestHandler(
  deps: HandlerDeps,
): (req: IncomingMessage, res: ServerResponse) => void;
```

```ts
// M-5 src/server.ts
import type { Server } from 'node:http';
import type { HandlerDeps } from './handler.ts';

export type TimeServerOptions = HandlerDeps;

export function createTimeServer(options: TimeServerOptions): Server;
```

```ts
// M-6 src/config.ts
export interface ListenConfig {
  readonly host: string;
  readonly port: number;
}

export type ConfigResult =
  | { readonly ok: true; readonly config: ListenConfig }
  | { readonly ok: false; readonly invalid: 'TOMATIME_HOST' | 'TOMATIME_PORT' };

export function parseConfig(env: Readonly<Record<string, string | undefined>>): ConfigResult;
```

- import は拡張子 `.ts` を付けて書き、型だけの import は `import type` にする（`verbatimModuleSyntax`、`allowImportingTsExtensions`。8 章）
- `formatJst` の引数を `unknown` にするのは、テストで注入した取得元が数でない値を返す場合も `non-finite` に分類するため（FR-4 の「有限の数でない値」）

### 4.2 外部インターフェース（要件定義書の再掲）

#### 応答

| 条件（判定順） | ステータス | ヘッダー（M-4 が `writeHead` に渡すもの） | `Date` | 本文 | 対応要件 |
|---|---|---|---|---|---|
| Node.js が要求を受け付けない | 400、408、417、431 | Node.js の既定（M-4 は関与しない） | 既定 | なし | FR-6 |
| メソッドが `GET` と `HEAD` 以外 | 405 | `Content-Type: text/plain; charset=utf-8`、`Cache-Control: no-store`、`Content-Length: 18`、`Allow: GET, HEAD` | 付く（Node.js の既定） | `method not allowed` | FR-5 |
| `GET` で取得・整形に失敗 | 500 | `Content-Type: text/plain; charset=utf-8`、`Cache-Control: no-store`、`Content-Length: 16` | 付けない（`res.sendDate = false`） | `time unavailable` | FR-4 |
| `HEAD` で取得・整形に失敗 | 500 | `GET` の 500 と同じ | 付けない | 送らない | FR-10 |
| `GET` で取得・整形に成功 | 200 | `Content-Type: text/plain; charset=utf-8`、`Cache-Control: no-store`、`Content-Length: 19` | 付く（Node.js の既定） | `YYYY-MM-DD HH:mm:ss`（日本時間、19 文字、末尾改行なし） | FR-1, FR-2, FR-3 |
| `HEAD` で取得・整形に成功 | 200 | `GET` の 200 と同じ | 付く | 送らない | FR-10 |

- `ETag`、`Last-Modified`、`Expires`、`Transfer-Encoding` を付けない。`Content-Length` は本文を `Buffer.byteLength(body, 'utf8')` で数えた値を文字列にして付ける（`HEAD` は同じ条件の `GET` の本文で数える）
- 本文・ヘッダーの値の定数は次の文字列と完全一致させる: `time unavailable`、`method not allowed`、`text/plain; charset=utf-8`、`no-store`、`GET, HEAD`
- `Connection`、`Keep-Alive` は Node.js の既定のままとする（要件定義書で規定しない）

#### 標準出力・標準エラー出力

| 出力先 | 出すモジュール | 文字列（LF で終わる 1 行） | 対応要件 |
|---|---|---|---|
| 標準出力 | M-7 | `listening: host=<アドレス> port=<ポート>` | FR-7 |
| 標準エラー出力 | M-7 | `startup failed: invalid <TOMATIME_HOST または TOMATIME_PORT>` | FR-7 |
| 標準エラー出力 | M-7 | `startup failed: <エラーコード> host=<アドレス> port=<ポート>` | FR-8 |
| 標準エラー出力（本番）または差し替えた書き込み先 | M-3 が作り M-4 が書く | `time unavailable: <原因>` | FR-4, FR-10 |

`<原因>` は M-3 の `failureLine` が次のとおり作る。

| `TimeFailure` | `<原因>` |
|---|---|
| `source-threw`、`thrown instanceof Error` | `source threw <name>: <message>` |
| `source-threw`、それ以外 | `source threw non-error value` |
| `non-finite` | `source returned non-finite value` |
| `out-of-range` | `source returned out-of-range value` |
| `internal`、`thrown instanceof Error` | `internal error <name>: <message>` |
| `internal`、それ以外 | `internal error non-error value` |

- `<name>` は `String(thrown.name)`、`<message>` は `String(thrown.message)`。それぞれの CR（U+000D）と LF（U+000A）を 1 文字ずつ半角空白に置き換える（`/[\r\n]/g` を `' '` に置換）。ほかの文字は変えない
- 1 行に発生時刻と取得元が返した値を含めない（FR-4 の補足）
