## 分析ツール

| 分からないこと | 手法を選ぶヒント |
|---|---|
| 目的と効果のつながり | 目標の因果関係を整理し、効果を測る指標を特定する |
| 境界と責任 | コンテキスト図で入出力、オニオン図で間接関係者、RACI で意思決定者を特定する |
| 業務の順序と分岐 | 業務フローで引き継ぎと例外、状態遷移図で可能・不可能な操作を確認する |
| データの整合性 | 概念 ER 図で関係・多重度、CRUD 表で操作・管理主体、ルール表で制約を確かめる |
| 操作や連携の認識 | ストーリーボードや試作で、判断が変わる箇所を関係者と確かめる |
| 採否や変更の影響 | 優先度の比較表と追跡表を使い、判断根拠と影響先を確認する |

分析資料は、その資料から何を決められるかで選ぶ。
