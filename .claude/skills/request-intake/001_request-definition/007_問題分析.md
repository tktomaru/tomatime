## 問題分析

- 問題を、現状と望ましい状態の差として記述する。誰がどの場面で困り、何が変われば解消と言えるかが分かると、指定された手段が有効か判断できる。
- 「なぜ」を繰り返すときは、各因果関係を観察、データ、当事者の説明で裏付ける。複数の原因がある場合は問題構造ツリーで分岐を残し、最初に思いついた原因で止めない。
- 提案された手段が実現しても問題が残る条件を探す。原因の候補は、その条件を説明できるか、対策後の変化を確認できるかで絞る。
- 発見の段階では候補を広く集め、評価の段階で目的への寄与、影響の大きさ、頻度、対策費用を見て絞る。未確認の原因や要求候補には、判断に必要な証拠を添える。
