## 非機能要求

| 観点 | 早めに気づく手掛かり |
|---|---|
| 性能・規模 | 平常時とピーク時、待ち時間を許せる工程と許せない工程を確かめる |
| 可用性・復旧 | 停止で止まる業務、許容停止時間・データ損失、代替手順を確認する |
| セキュリティ・法令 | 利用主体、情報の公開範囲、保存・監査義務を確かめる |
| 運用・保守・移行 | 監視・復旧の担当、引き継ぐデータ、切替や切り戻し中の制約を調べる |
| 利用環境・外部依存 | 利用機器、接続条件、アクセシビリティ、変更できない連携先の条件を確かめる |

- 利用者が意識しにくい品質は調査側から提示する。水準を上げる費用と、下げた場合に誰が負う損失を比べ、必要な水準を聞く。安全や法令の必須条件は先に押さえる。
- 数値や基準が未定なら、業務上の許容範囲と測定条件を確認事項にする。確認して対象外とした観点は理由を残す。
