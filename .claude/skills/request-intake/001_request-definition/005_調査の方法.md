## 調査の方法

- 発言は目的と判断理由、文書は正式ルール、観察は運用の実態、データは頻度と結果の確認に使う。資料の版・対象範囲・観測時点が揃っているか確かめ、差分は運用条件や変更履歴と照らす。
- 広がりを測るならアンケート、部門間の違いを調べるなら関係者を集めた検討、投資目的を確かめるなら意思決定者への確認が向く。広く集めた回答の理由は対象を選んで聞き直す。
- スキーマから分からない分布と意味を調べる。欠損と有効なゼロ、負値と訂正、重複、最大長・最大件数、未知のコード、旧ルールのデータ、関連データの不整合を確かめる。
- 観測された挙動をそのまま将来の仕様にすると、旧仕様や不具合まで引き継ぐ。互換性が必要な挙動と改める挙動を判断できるよう、利用者への影響と証拠を残す。
