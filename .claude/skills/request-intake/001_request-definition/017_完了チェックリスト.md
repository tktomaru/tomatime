## 完了チェックリスト

対象外にした観点は理由を説明できる状態にする。未確定でも進められる論点は、影響と次の確認方法を残す。

- [ ] 目的、解決すべき問題、成功の判定、対象内・対象外が読み取れる。
- [ ] 利用者、運用者、結果の受け手、意思決定者を把握し、重要な解釈を当事者に確認した。
- [ ] 現状と望む業務を照合し、システム境界、暗黙のルール、正常時・失敗時・例外時の論点を確認した。
- [ ] 依頼原文と要求を双方向にたどれる。要求の優先度を目的と、見送りによる影響から説明できる。
- [ ] 用語・指標、実データ、データの粒度・関係・境界、既存機能や外部連携への影響を確認した。
- [ ] 性能、可用性、運用、アクセス、移行といった品質上の論点が判断済みか、確認事項になっている。
- [ ] 解釈の違い、矛盾、実現性の不明点に、選択肢・影響・確認先がある。仮定に依存する見積もりや判断を特定できる。
- [ ] レビューの根拠、決定理由、残ったリスク、次の工程に渡す論点が記録され、必要な合意と変更手順を確認した。
