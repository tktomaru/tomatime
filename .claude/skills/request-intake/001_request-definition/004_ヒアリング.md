## ヒアリング

- 手元の資料と回答済みの内容を先に確認し、答えで判断が変わる論点に絞る。考える時間が必要な論点は事前に共有する。
- 一般論から始めると建前が返りやすい。普段の流れと実際に外れたときの事実を順に聞き、誰が何を見て、何を決め、誰に渡すかを追う。発生頻度と影響は別に確かめる。
- 説明が食い違うときは、役割、時期、部門、運用条件の違いを先に調べる。実態が分かった後に、その運用を残すか変えるかを決める。
- プロセス質問で調査そのものを点検する。回答の代表性、質問の前提、見落とした立場、反対意見、詳しい人を確認すると、同じ相手への質問を増やすだけでは届かない情報が得られる。
- 確認事項は一件一論点にし、選択肢と結果の差、推奨と理由、推測で進むリスクを示す。回答次第で後続の質問が不要になる論点や、後戻りの難しい論点を先に聞く。
- 回答はすぐに記録し、重要な解釈や判断は本人に読み返してもらう。推奨や聞き手の解釈は、確認済みの内容と区別する。
