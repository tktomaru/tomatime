## 用語とデータの粒度

- 同じ用語でも、部署や工程ごとに対象、基準時点、含める条件が違うことがある。用語・指標には対象、算出方法、単位、期間、除外条件を紐づける。意味を一つにできない場合は適用範囲を示す。
- 欲しい情報から、その情報で行う判断、取る行動、期待する効果を逆にたどる。判断を変えない情報は優先度を見直し、必要な判断に情報が足りなければ要求候補にする。
- 入手できる元データと必要な出力で、単位、集計期間、精度、更新頻度、履歴の揃い方を比べる。粗い粒度から細部は復元できないため、出力の変更や取得方法の見直しが必要かを確かめる。
- 業務を処理するシステムは更新の整合性と例外、分析や意思決定を支援するシステムは元データの品質と指標の定義を重点的に調べる。誤った結果の影響が大きい箇所は、誤りを検知した後の扱いも確認する。
