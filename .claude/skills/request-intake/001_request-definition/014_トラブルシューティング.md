## トラブルシューティング

| 兆候 | 原因を見つけて進めるヒント |
|---|---|
| 同じ議論を繰り返す | 決定者、決定の記録、見直す条件を確認する。再議論するなら前提が変わった箇所を明示する |
| 範囲が広がり続ける | 目的と成功条件で候補を評価し、今回見送った場合の影響を比べる |
| 要求が出ない・回答が得られない | 調査の負担と質問の意義を確かめ、実際の業務や最小限の試作を手掛かりに選択肢を示す |
| 説明が食い違う | 役割、運用条件、時期の違いを調べ、共通ルールか条件別のルールかを判断する |
| 文書化が進まない | 小さな単位で分かったことを記録し、未決事項を見える状態にして早めにレビューする |
| 終盤に同種の不備が重なる | 初めて見つかった工程から逆にたどり、調査の観点、判断時期、レビューのどこで検知できるかを見直す |
