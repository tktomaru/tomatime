## 品質条件と設計判断

1. 設計案の選択を左右する品質要件について、承認済みの要件に沿って測定条件・指標・合否基準を明確にする。運用時に検証する項目は、確認するログや指標も決める。
2. 撤回に費用がかかる判断は、代替案の利点と欠点を比較し、設計書の「検討した代替案」に採用理由を残す。検証方法、戻し方、再検討する条件を設計書の該当章に記録する。 [検討した代替案の書式](../../../../../docs/900_templates/003_design/010_検討した代替案.md)
3. 守るべき境界と依存方向を「実装への引き継ぎ」に記載する。差し替え点と再現する条件は設計書の「テスト容易性」に記録する。 [テスト容易性の書式](../../../../../docs/900_templates/003_design/007_テスト容易性.md)
