## 境界と依存関係

1. 変更の影響を局所化するために必要な箇所へ境界を置く。責務と依存方向は作成する設計書の「モジュール構成」、境界をまたぐ入出力は「公開インターフェース」に記録する。 [モジュール構成の書式](../../../../../docs/900_templates/003_design/003_モジュール構成.md)・[公開インターフェースの書式](../../../../../docs/900_templates/003_design/004_公開インターフェース.md)
2. 失敗時の振る舞いを設計書の「エラー処理」に記録する。外部連携やデータの扱いを変える場合は、該当する入力検証・認可、データの所有者、障害時に残る状態と復旧方法も決める。 [エラー処理の書式](../../../../../docs/900_templates/003_design/006_エラー処理.md)
